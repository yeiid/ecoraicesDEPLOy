## 4. Calendario de lanzamiento (30 días)

### Semana 1 — Teaser & anuncio
| Día | Formato | Contenido |
|---|---|---|

| 3 | Reel | "3 razones para registrar un árbol hoy" (1. datos para la ciencia, 2. protección, 3. comunidad). |
| 4 | Post carrusel | ¿Qué es EcoRaíces? (misión → cómo funciona → para quién → CTA). |
